## 5.1 再現性: 約束と現実

原理的には、SDL は再現性製造機です: ロボットは同一動作を実行し、全パラメータが記録され、キャンペーンはログから再生できます。しかし実際には 3 つのギャップが残ります:

1. **隠れ変数**: 試薬ロット、環境湿度、装置ドリフト — ロボットが忠実に再現するのは*コマンド*であって*条件*ではない。成熟したプラットフォームが環境センサーと試薬メタデータを記録するのはこのため。
2. **プラットフォーム間の移植**: ある分注機で調整されたプロトコルは、別の分注機でしばしば失敗する。同じ「レシピ」がハードウェアの癖（分注速度、デッドボリューム）と絡み合っている。同一キャンペーンを複数プラットフォームで走らせるラウンドロビン研究は始まったばかり。
3. **解釈の再現性**: A-Lab 論争（第 4 章）が示したように、同一の生データからでも 2 つの解析パイプラインは*何が合成されたか*について意見が分かれうる。生データ + 解析コードの公開が新たな規範であり、必須と考えるべきです。

> **経験則**: SDL の結果の再現性は、*最も記録が甘い*入力と同じ水準でしかない。

## 5.2 標準化

今日のあらゆる SDL には数ヶ月分の特注グルーコードが入っています。標準はそのコストの償却を狙います:

| 標準 | 守備範囲 | 状況 |
|---|---|---|
| **SiLA 2** | 装置通信（デバイスのコマンド/テレメトリを標準化サービスとして提供） | ベンダー採用が拡大中。バイオ主導 |
| **AnIML** | 分析データ交換フォーマット（メタデータ付きスペクトル・クロマトグラム） | 確立された XML 標準。装置カバレッジは部分的 |
| **XDL** | 実行可能な化学手順記述（Chemputer エコシステム） | エコシステム内でハードウェア横断実行を実証 |
| **Bluesky ドキュメント** | 放射光発のイベントベース実験データモデル | ビームラインの事実上の標準。ラボへ普及中 |

どれも万能ではありません。2026 年の実務的現実は**アダプタ層**です: オーケストレータ（第 3 章）が内部で各装置の方言を話し、上位にはきれいなインターフェースを見せる。ただし方向性は初期のコンピューティングと同じ — カスタムドライバからプラグアンドプレイへ — であり、これから装置を選ぶグループにはプログラマブルなインターフェースを持つベンダーを推奨します。

## 5.3 データ: FAIR・失敗・共有

SDL は機械学習が必要とするまさにそのデータ — 高密度、均質、来歴付き — を生み、人間が決して公表しない**負の結果**まで含みます。未解決問題は 3 つ:

- **インセンティブ**: キャリアの報酬は論文であってデータセットではない。キャンペーンの 700 実験ログを預託してもほとんど評価されないため、SDL データの大半は今も研究室のサーバーに眠っている。
- **スキーマ**: 「組成・プロセス・物性」は、ある研究室が温度ランプを記録し別の研究室が設定値だけを記録する現実の前では単純ではない。コミュニティスキーマとリポジトリ（Materials Data Facility、NOMAD、日本では NIMS の MDR）は徐々に収束しつつある。
- **基盤モデルへの活用**: 実験ループの大規模共有コーパスがあれば、事前学習済みの「実験事前分布」— 新しいキャンペーンに、典型的なプロセス–物性地形を既に知った状態で臨むモデル — が可能になる。コンソーシアム規模のデータ共有の大きな動機です。

```python
# FAIR 流の記録: すべてのログ済み実験が最低限持つべきもの
record = {
  "sample_id": "SDL-2026-0812-041",
  "composition": {"Cu": 0.45, "Zn": 0.30, "Al": 0.15, "Mn": 0.10},
  "process": {"T_C": 450, "t_min": 120, "atmosphere": "N2"},
  "raw_files": ["xrd/041.xy", "uvvis/041.csv"],
  "derived": {"activity_umol_g_h": 485.0},
  "provenance": {"planner": "EHVI-v2", "reagent_lots": {"CuNO3": "L2419"},
                  "instrument_ids": ["furnace-2", "xrd-1"], "code_rev": "9f3ab21"}
}
```

## 5.4 コスト・アクセス・クラウドラボ

専用 SDL の構築費は、オープンソースの分注ループで約 5 万ドルから、A-Lab 級の固相ラインで数百万ドルまで — さらに 2〜3 人年の統合エンジニアリングが乗ります。3 つのアクセスモデルが出現しています:

1. **所有**: 大規模グループや企業が、機密キャンペーンのために自前プラットフォームを構築する
2. **共有**: コンソーシアム施設 — 例えばトロント大学の **Acceleration Consortium**（カナダ研究史上最大級の研究助成に支えられる）— が会員向け共有インフラとして SDL を運用する
3. **賃借**: クラウドラボ（商用の遠隔操作施設、IBM RoboRXN 型サービス）が実験をサービスとして販売する。研究者はプロトコルを書き、施設が実行する

行き着く均衡はまたもコンピューティングに似るでしょう: 定型キャンペーンは共有・クラウド施設へ移り、最先端ハードウェアは専門ラボに残る。学生にとっての含意は、**SDL リテラシー — 問題を目的関数・探索空間・制約として定式化する力 — がロボットの所有より重要**だということです。

## 5.5 人間の役割

SDL は科学者を排除しません。配置転換するのです:

| タスク | SDL 以前 | SDL 以後 |
|---|---|---|
| 個々の実験の選択 | 科学者の勘 | プランナー |
| 分注・秤量・測定 | 手作業 | ロボット |
| 目的関数と制約の定義 | 暗黙的 | **科学者の中核業務** |
| 想定外・異常の判断 | 科学者 | **科学者（より良いデータ付きで）** |
| 勝者の検証と解釈 | 科学者 | 科学者 |
| ループの構築と維持 | — | 新しいエンジニアリング職 |

人材面の含意は 2 つ。第一に、化学・材料のドメイン知識*と*ソフトウェア・データスキルを併せ持つハイブリッド人材の需要が伸び、カリキュラム（本シリーズを含む）が適応しつつあります。第二に、**科学的判断のレイヤーが上に移動**します: *何を最適化する価値があるか*を決めること、目的関数が微妙にずれていることを見抜くこと、異常を追及すること — それが人間の最高価値の活動になります。機械は探索し、人は探索の意味を決める。

## 5.6 世界の動き

- **カナダ**: Acceleration Consortium（トロント）— 共有 SDL の旗艦プログラム。Ada の系譜（UBC）は材料・化学で継続中
- **米国**: MGI エコシステム、国立研究所のプラットフォーム（LBNL の A-Lab、BNL/APS の Bluesky によるビームライン自律化）、大学のフロー化学 SDL
- **欧州**: 強力な自動合成グループ(グラスゴーの Chemputer、リバプールの移動ロボット)、EU の材料加速プログラム
- **日本**: **NIMS** が自律実験オーケストレーションの NIMO と NIMS-OS を開発し、データ基盤（MDR）を運用。大学・企業は MI とロボティクスを結ぶプログラムの下で電池・触媒・ポリマーの SDL を運用中。製造業の自動化基盤を持つ日本はハードウェア面で特に強い
- **世界的枠組み**: Mission Innovation の Materials Acceleration Platform 構想が共有ロードマップであり続けている — SDL はクリーンエネルギー材料開発を加速する実験エンジン

## 5.7 展望: これからの 5 年

現在のフロンティアから見える潮流:

1. **自動解釈の高度化** — 不確かさを扱える相同定・スペクトル解析。A-Lab の教訓への直接の応答
2. **LLM ベースのラボエージェント** — 自然言語でのキャンペーン仕様記述、文献に基づくレシピ提案、異常のトリアージを BO プランナーの上に重ねる
3. **マルチフィデリティループ** — シミュレーション・安価な代理測定・本実験を統合計画し、高価な測定はモデル間の不一致がある場所にだけ投じる
4. **レベル 4 自律** — パラメータ調整だけでなく、自らのワークフローを修正する（新しい前駆体、追加のキャラクタリゼーション）システム
5. **連合キャンペーン** — 5.2 節の標準に支えられ、1 つのプランナーが複数拠点のハードウェアを操縦する

正直な総括はこうです: 今日の SDL は、**良く定式化された最適化キャンペーンを 10〜100 倍加速することが実証済みの専門装置**であり、汎用で信頼でき共有される科学インフラへはまだ成熟の途上にあります。残る障害はロボットの問題というより、**解釈・標準・インセンティブ・人**の問題です。

## 5.8 シリーズのまとめ
