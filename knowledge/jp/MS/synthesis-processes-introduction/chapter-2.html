2.1 ゾル-ゲル法

ゾル-ゲル合成は、液体前駆体から加水分解反応と縮合反応を通じて材料を作り出す手法です。

📐 加水分解と縮合: $$Si(OR)_4 + 4H_2O \rightarrow Si(OH)_4 + 4ROH$$ $$Si(OH)_4 \rightarrow SiO_2 + 2H_2O$$

💻 コード例1: ゾル-ゲルのゲル化モデリング

# 必要環境:
# - Python 3.9+
# - matplotlib>=3.7.0
# - numpy>=1.24.0, <2.0.0

import numpy as np
import matplotlib.pyplot as plt

def solgel_gelation_time(pH, temp):
    """ゲル化時間をモデル化する"""
    T = temp + 273
    t_gel = 100 * np.exp(0.5*(pH-7)**2) * np.exp(5000/(8.314*T))
    return t_gel

pH_vals = np.linspace(1, 13, 100)
t = [solgel_gelation_time(pH, 60) for pH in pH_vals]

plt.semilogy(pH_vals, t, 'b-', linewidth=2)
plt.xlabel('pH')
plt.ylabel('Gelation Time (min)')
plt.grid(True, alpha=0.3)
plt.show()
