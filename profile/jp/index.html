材料データをAIで読み解き、ロボットで合成条件を探る

東北大学 学際科学フロンティア研究所 特任准教授。マテリアルズ・インフォマティクス、自律実験システム、マルチエージェントAIによる自律データ分析を研究しています。

研究内容を見る 共同研究について

現在の研究の3本柱

実験・計算データの統合、ロボットによる自動合成、AIエージェントによる自律的なデータ分析を組み合わせ、材料開発の進め方そのものを研究しています。

🗺️

材料マップ

実験データベース Starrydata2 と計算データベース Materials Project を統合し、グラフベースの機械学習で材料マップを構築。有望な熱電材料の類似物質を探索します。

Y. Hashimoto, X. Jia, H. Li, T. Tomai, APL Machine Learning 3, 036104 (2025)

研究内容 論文（DOI）
🦾

MOF自動合成

ロボットアームと電動ピペットで原料溶液の注入速度を制御する自動合成システムを構築。ZIF-8では注入が遅いほど粒径が大きくなる傾向を確認し、注入量・速度・温度などのプロセスデータをメタデータとして記録してプロセス・インフォマティクスにつなげます。

化学工学会 第57回秋季大会 口頭発表（2026年9月14日）

研究内容 講演詳細
🧠

マルチエージェントAIによる自律データ分析

Claude Code 上に実装した3層9体のマルチエージェントAIが、熱電材料データベース Starrydata2 を自律的に分析。417プロジェクトから約8,110件の知識エントリを生成し、サイクル間で知識を継承することで探索が拡張・深化することを確認しました。

データ駆動型材料科学研究会 2026年夏季年会（2026年7月6日）、Agentic AI Summit 2026・UC Berkeley ポスター（2026年8月1–2日）、第87回応用物理学会秋季学術講演会（2026年9月10日）
