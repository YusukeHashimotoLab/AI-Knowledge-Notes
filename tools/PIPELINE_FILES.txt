wp/tools — file inventory
=========================

Paths are relative to wp/. Run every command from wp/.
Dependencies: wp/requirements.txt (the only dependency list in this repository).

Scripts
-------
tools/convert_md_to_html.py
  Markdown -> HTML for both locales (knowledge/en and knowledge/jp).
  One positional target: .md file, series directory, or bare dojo name; omit it to
  convert a whole locale. Locale is read from knowledge/<en|jp>/ in the path, else
  --lang en|jp, else defaults to en.
  Needs: Markdown, PyYAML. Covered by scripts/test_convert_md_to_html.py.

tools/html_to_md.py
  HTML -> Markdown with YAML frontmatter recovery.
  Usage: html_to_md.py <file-or-dir> [--output-dir DIR] [--no-backup]
  A directory argument is scanned non-recursively for chapter*.html, so pass one
  series directory at a time. Needs: html2text, beautifulsoup4. No test coverage.

tools/sync_md_html.py
  Bidirectional sync, direction chosen by modification time.
  Usage: sync_md_html.py [path] [--dry-run] [--force-direction md2html|html2md] [--watch]
  Series directories and single files work for both locales; a bare dojo name or a
  locale root resolves against knowledge/en only (BASE_PATH), and a dojo *directory*
  matches nothing. Shells out to the two converters above; --watch needs watchdog.

tools/batch_html_to_md.py
  Wrapper around html_to_md.py that walks every *.html under a directory (not just
  chapter*.html). Usage: batch_html_to_md.py <knowledge_dir> [--no-backup]
  Needs: html2text, beautifulsoup4.

tools/validate_mermaid.py
  Mermaid syntax validator, standard library only. Usage:
  validate_mermaid.py [target]  (no target = whole knowledge base). Exits 1 on error.
  Run by CI in both repos. Covered by scripts/test_validate_mermaid.py.
